    Guided setup

    Add a game

    Choose your game

    Use a trusted installer, or a game already installed on this computer. Each game gets its own Wine environment (prefix). Existing game files stay in place; back up your saves first.

    Most systems use /usr/bin/wine. To use another version, such as Wine-GE, choose its bin/wine. Proton's wrapper isn't supported. No runners are downloaded.

    Compatibility and installer options

    Local setup runs Windows software with your user permissions, not inside a sandbox or VM. Keep the runner and game files at their chosen paths.
