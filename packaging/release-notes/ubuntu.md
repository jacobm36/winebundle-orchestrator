**Winebundle for Ubuntu** installs your Windows games on Linux and adds them to your
application menu, each in its own Wine setup, with no terminal needed.

### Install

Download `winebundle_*_all.deb` below, then run:

```bash
sudo apt install ~/Downloads/winebundle_*_all.deb
```

Open **Winebundle** from your application menu. Installing a newer release the same way
updates it; your games are kept. Tested on Ubuntu 24.04.
See the [Ubuntu guide](https://github.com/jacobm36/winebundle-orchestrator/blob/master/docs/UBUNTU.md).
